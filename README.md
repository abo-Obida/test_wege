# Testwege

This is a small online shop project built with Next.js for a fashion and lifestyle brand. The app has a clean landing page, a product listing page, and a product detail view so it feels close to a real storefront.

I put together the layout, styling, and product structure in a simple way so it is easy to understand and adapt later. The design is minimal, modern, and meant to look like a proper brand website instead of a demo template.

## How to run it

```bash
npm install
npm run dev
```

Then open this in the browser:

http://localhost:3000

## Build for production

```bash
npm run build
```

## Project idea

The project is meant to show a boutique-style catalog with:

- a homepage with branding and hero section
- a products page with product cards
- a product details page
- a quick view modal and basic shopping UI

## Notes

This is still a basic version, and a few details may need small ajustments later as the design gets more polished.
